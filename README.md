Хід роботи
1. Вибір теми проекту
Я вирішив створити імітацію e-commerce магазину, оскільки це дає змогу продемонструвати різні аспекти веб-розробки, взаємодії з користувачем і роботу з базою даних.
________________________________________
2. Структура проекту
На першому етапі я створив базову структуру проекту, яка включає такі папки:
•	static – для збереження стилів, зображень та скриптів
•	templates – для HTML-шаблонів
•	models – для роботи з базою даних
•	routes – для організації маршрутів
•	main.py – головний файл для запуску FastAPI
 
Після цього я встановив основні залежності:
•	FastAPI – для розробки бекенду
•	Jinja2 – для роботи з шаблонами
•	Uvicorn – для запуску ASGI сервера
________________________________________
3. Розробка базових шаблонів
Наступним кроком було створення шаблонів.
•	base.html – основний шаблон для всіх сторінок, містить:
o	Навігаційне меню
o	Підключення Bootstrap та Font Awesome
o	Футер з контактною інформацією
•	index.html – головна сторінка магазину, де реалізовано:
o	Привітальний банер
o	Блоки з перевагами магазину
o	Секція з категоріями товарів
________________________________________
4. Налаштування маршрутизації
В main.py я налаштував FastAPI:
•	Підключив статичні файли
•	Створив маршрут для головної сторінки
________________________________________
5. Проектування бази даних
Я визначив основні таблиці для магазину, використав бд Sqlite:
•	Users – зберігання інформації про користувачів
•	Products – каталог товарів
•	Orders – таблиця замовлень
•	Cart – кошик покупок
________________________________________
6. Реалізація системи аутентифікації
•	Реєстрації нових користувачів
•	Авторизації через email/пароль
•	Розподілу ролей (звичайні користувачі та адміністратори)
